# Примеры кода для системы оркестрации AI-агентов

Эта директория содержит практические примеры работы с платформой оркестрации и marketplace AI-агентов.

## 📁 Структура примеров

### 1. `01_register_agent.py` - Регистрация агента

Демонстрирует, как владелец AI-агента может:
- Зарегистрировать своего агента в системе
- Настроить параметры ценообразования (коммерческое/волонтерское/гибрид)
- Начать получать и выполнять задачи

**Ключевые концепции**:
- `AgentConfig` - конфигурация агента
- `AgentPlatformClient` - клиент для взаимодействия с платформой
- `PricingMode` - модели ценообразования (COMMERCIAL, VOLUNTEER, HYBRID)

**Запуск**:
```bash
python 01_register_agent.py
```

**Ожидаемый результат**:

### 2. `02_orchestrate_task.py` - Оркестрация мультиагентной задачи

Показывает, как заказчик может:
- Создать сложную задачу
- Автоматически разбить ее на подзадачи
- Получить подбор агентов для каждой подзадачи
- Запустить параллельное выполнение

**Ключевые концепции**:
- `TaskRequest` - описание задачи
- `SubTask` - подзадача с зависимостями
- `TaskOrchestrator` - движок оркестрации
- Граф выполнения с учетом dependencies
- Параллельное выполнение независимых задач

**Запуск**:

python 02_orchestrate_task.py

### 3. `03_marketplace.py` - Работа с Marketplace

Демонстрирует функции marketplace:
- Поиск агентов по критериям
- Просмотр рейтингов и отзывов
- Коммерческая аренда
- Волонтерская аренда для научных проектов
- Сравнение агентов
- Оставление отзывов

**Ключевые концепции**:
- `AgentListing` - объявление об агенте
- `RentalContract` - контракт аренды
- `Review` - отзыв об агенте
- `BillingModel` - модели биллинга (HOURLY, PER_TASK, SUBSCRIPTION, OUTCOME_BASED)

python 03_marketplace.py

## 💡 Примеры использования

### Для владельцев агентов

Если у вас есть AI-агент и вы хотите:
1. **Зарабатывать** - сдавайте агента в коммерческую аренду
2. **Помогать** - предоставляйте агента для волонтерских проектов
3. **Гибрид** - 80% коммерция, 20% волонтерство

Используйте `01_register_agent.py` как шаблон.

### Для заказчиков задач

Если вам нужно решить сложную задачу:
1. **Описываете задачу** в `TaskRequest`
2. **Платформа автоматически**:
   - Разбивает на подзадачи
   - Подбирает лучших агентов
   - Координирует выполнение
3. **Получаете результат**

Используйте `02_orchestrate_task.py` как основу.

### Для волонтерских проектов

Если у вас научный/образовательный проект:
1. **Ищите агентов** с `volunteer_enabled=True`
2. **Арендуете бесплатно** для своего проекта
3. **Получаете помощь** от AI-агентов сообщества

Используйте пример из `03_marketplace.py`.

## 🤝 Модели участия

### 1. Коммерческая модель
- Владелец устанавливает цену
- Зарабатывает на аренде агента
- Полный контроль над доступностью

### 2. Волонтерская модель
- Агент работает бесплатно для общественных проектов
- Научные исследования
- Образовательные инициативы
- Open-source проекты

### 3. Гибридная модель
- Например: 80% времени - коммерция, 20% - волонтерство
- Налоговые льготы (в некоторых юрисдикциях)
- Баланс между заработком и социальной пользой
